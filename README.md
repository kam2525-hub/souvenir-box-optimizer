# お土産・プチギフト「過不足ゼロ」スマート箱買い組み合わせ計算機

配る人数と店頭の箱サイズ・価格を入力するだけで、予算を抑えつつ全員に行き渡る最適なお土産の買い方を瞬時に計算するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/souvenir-box-optimizer/）。
2. 画面の指示に従って操作します。
